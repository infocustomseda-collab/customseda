# Original photographs

These are byte-identical originals preserved from the local EmDash R2 media library, not generated WebP derivatives. No image download from the former platform is needed.

- `products/`: photography referenced by Products and Conjuntos.
- `site/`: campaign, story, process and other supporting photographs.
- `manifest.json`: stable EmDash media ID, R2 storage key, original filename, relative path, byte count and SHA-256 for each file.

The initial archive contains 95 files, totalling 210,164,752 bytes. Shared images are stored once. The infrastructure smoke-test pixel is excluded.

Run `pnpm media:originals` to refresh the archive from local R2 after adding media. This command only reads local CMS/R2 and writes archive files; it never changes CMS records. Review the manifest and remove any obsolete local files separately when deliberately retiring media.

Keep media IDs and storage keys intact when restoring to R2 so editable gallery and page references continue to resolve. Public responsive images remain generated by the existing build pipeline into ignored `public/media/`.
